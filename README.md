# Praktikum 7 - Server Side PHP

## 1. Tujuan
Mempelajari dasar pemrograman PHP, penggunaan variabel, array, function, metode GET dan POST, serta validasi form menggunakan PHP.

## 2. Perangkat yang Digunakan
- Sistem Operasi Windows
- Visual Studio Code
- XAMPP
- PHP
- Web Browser

## 3. Cara Menjalankan Server Lokal
1. Buka aplikasi XAMPP.
2. Aktifkan Apache.
3. Simpan folder proyek `Lab7Web_PHP` di dalam folder `htdocs`.
4. Buka browser.
5. Masukkan alamat berikut:

   `http://localhost/Lab7Web_PHP/`

## 4. Struktur File
- `mini_project/index.php` : Formulir data mahasiswa dan validasi input.
- `dokumentasi.php` : Halaman gabungan untuk dokumentasi praktikum.

## 5. Ringkasan Hasil
Praktikum ini menghasilkan beberapa program PHP yang menerapkan konsep dasar pemrograman server-side. Program dapat dijalankan melalui web server lokal menggunakan XAMPP.

Selain itu, mini project formulir data mahasiswa berhasil menerapkan metode POST, validasi input, dan penggunaan `htmlspecialchars()` untuk menampilkan data dengan lebih aman.
